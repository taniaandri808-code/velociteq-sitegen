VelociTeX: a faster drop-in static site build that returns makefun-site 1.0.0's output tree byte for byte, with a chunked inline Markdown renderer, a tight block lexer, cached slugs and a slim template renderer.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
